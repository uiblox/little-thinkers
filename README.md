This is a start to a collection of simple apps to help children learn.

## Balance the Eequation

Introduction for 1st graders to equations

![Balance Equations](./public/balance-equations.png)

## Star Typer

A Star Wars-style space shooter that teaches kids to touch type. Open `learn-to-type.html` in a browser: type the letters (and later, words) on falling enemy ships to blast them. The on-screen keyboard highlights the next key and names the finger to use.
